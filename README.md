## 概要
Cinema-Corporate は中小企業向けコーポレートサイトを想定した
オリジナルWordPressテーマです。

## 技術スタック
- WordPress（オリジナルテーマ開発）
- PHP
- HTML / CSS
- Docker（ローカル開発環境）
- Contact Form 7（お問い合わせ機能）

## 主な機能
- グローバルナビゲーション
- Service（カスタム投稿タイプ）
  - 一覧ページ / 詳細ページ
- 固定ページ（Contact / プライバシーポリシー等）
- フッター
  - 3カラムウィジェット
  - フッターナビ
  - コピーライト

- お問い合わせ機能（Contact Form 7）
- 検索機能
- 404ページ
- サイトマップページ
- パンくずリスト

## 実装詳細
### カスタム投稿タイプ（Service）
- `register_post_type` を使用して独自投稿タイプを実装
- 管理画面からサービス情報を登録・編集可能
- アーカイブページと詳細ページをテーマ側でカスタマイズ

### パンくずリスト
- functions.php にてパンくず生成ロジックを実装
- 投稿タイプ・階層構造に応じて動的に生成
- 各テンプレートで共通表示

### JSON-LD（構造化データ）
- BreadcrumbList を JSON-LD 形式で出力
- `wp_head` フックで埋め込み

## SEO対策
- メタディスクリプションの動的出力
- OGPタグの実装
- JSON-LDによる構造化データ（BreadcrumbList）
- canonicalの設定
- 不要ページへの noindex 指定

## お問い合わせフォームについて
お問い合わせページは **Contact Form 7** プラグインを利用して実装しています。

- テーマ側ではページテンプレート（`page-contact.php`）を作成し、
  レイアウトおよびデザインのみを担当
- フォームの入力チェックやメール送信処理はプラグインに委譲することで、
  テーマと機能の責務を分離
- 開発環境では Docker を使用しているため、実メール送信は行わず、
  フォームの表示・バリデーション・エラー表示までを確認
- 本番環境では SMTP を利用したメール送信を想定

## 設計方針
- テーマと機能の責務を分離
  - お問い合わせ機能はプラグインに委譲
- 再利用性を意識したテンプレート構成
- SEOを意識したマークアップ設計
