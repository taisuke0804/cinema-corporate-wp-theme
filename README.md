## 概要
Cinema-Corporate は中小企業向けコーポレートサイトを想定した
オリジナルWordPressテーマです。

## 開発環境
- Docker
- WordPress
- PHP

## 現在の実装
- グローバルナビ
- Service（カスタム投稿）
- 一覧・詳細ページ
- Contact（お問い合わせページ）

## Contact 機能について
お問い合わせページは **Contact Form 7** プラグインを利用して実装しています。

- テーマ側ではページテンプレート（`page-contact.php`）を作成し、
  レイアウトおよびデザインのみを担当
- フォームの入力チェックやメール送信処理はプラグインに委譲することで、
  テーマと機能の責務を分離
- 開発環境では Docker を使用しているため、実メール送信は行わず、
  フォームの表示・バリデーション・エラー表示までを確認
- 本番環境では SMTP を利用したメール送信を想定
